# Amir Video Saver

**Amir Video Saver** — удобное десктопное приложение для скачивания постов, фото
и видео из Telegram-каналов и групп.

Приложение работает через ваш аккаунт Telegram, поддерживает несколько профилей,
показывает аватарки каналов, сохраняет тексты постов и создаёт удобный
Excel-навигатор со ссылками на все файлы.

---

## Возможности

- Скачивание **текстов**, **фото** и **видео** из каналов и групп
- Поддержка нескольких аккаунтов (профили)
- Аватарки каналов в списке
- Выбор количества постов (все / последние 5 / 20 / 100 / 500)
- Пробный режим («Оценить объём») — показывает, сколько места займёт скачивание
- Автоматическое создание Excel-навигатора (`0_navigator.xlsx`) со ссылками
- Возможность докачки (уже скачанные файлы пропускаются)
- Тёмная и светлая тема
- Работа с приватными каналами (при условии, что вы на них подписаны)

## Как забрать id telegram (объясняю по этапно)

Сначала, когда вы еще не зарегистрировались в telegram api

1. Откройте [https://my.telegram.org](https://my.telegram.org) и войдите (код
   придёт сообщением в приложение Telegram).
2. Зайдите в **API development tools** (или просто в **Development tools**). Вы
   увидите уже созданное приложение и второй раз создавать его не нужно.
3. Скопируйте оттуда:
   - **App api_id** (только цифры)
   - **App api_hash** (32 символа из букв и цифр)

Эти два значения понадобятся при создании профиля внутри программы.

> **Важно:** один `api_id` + `api_hash` можно использовать только в одном в
> вашем профиле приложения, на которые вы подписались с вашего аккаунта!

4. После авторизации вам попросят - отсканировать QR-код, следуя инструкции,
   которые там написано
5. И напоследок вы должны ввести ваше имя, т.к сказать чтобы путаницы не было,
   кому принадлежит этот аккаунт

### Три значения в .env берутся из разных мест

| Переменная  |                   Откуда                    |           Как выглядит           |
| :---------: | :-----------------------------------------: | :------------------------------: |
|  TG_API_ID  | [my.telegram.org](https://my.telegram.org/) |             12345678             |
| TG_API_HASH | [my.telegram.org](https://my.telegram.org/) | 0123456789abcdef0123456789abcdef |
| TG_CHANNEL  |           вывод list_channels.py            |          -1001234567890          |

## Алгоритм: скачивание приватного канала со своего аккаунта

### Шаг 1. Подготовка проекта

1. Папка проекта `tg-video-downloader`, в ней `.venv` и установленные
   зависимости из `requirements.txt`.
2. Окружение активно: в терминале виден `(.venv)`.

### Шаг 2. Ключи приложения

1. На https://my.telegram.org → API development tools возьмите `api_id` и
   `api_hash`.
2. Впишите их в `.env`, `TG_CHANNEL` пока оставьте пустым:
   ```env
      TG_API_ID=12345678
      TG_API_HASH=0123456789abcdef0123456789abcdef
      TG_CHANNEL=
   ```
   Без кавычек и пробелов, в файле только эти строки.

### Шаг 3. Вход в аккаунт

1. Если остался старый `session.session`, удалите его вместе с
   `session.session-journal`.
2. Запустите `python list_channels.py`.
3. Введите номер в формате `+77XXXXXXXXX`. Номер должен принадлежать аккаунту,
   который подписан на канал.
4. Введите код из чата «Telegram» в приложении (и облачный пароль, если он
   включён).
5. Появится файл `session.session`. Теперь вход выполнен, и номер больше не
   спросят.

### Шаг 4. Узнать ID канала

1. Откройте созданный `channels.csv`.
2. Найдите нужный канал по названию и скопируйте число из столбца `id` целиком,
   с минусом и `-100`.

### Шаг 5. Вписать ID

```env
TG_CHANNEL=-100XXXXXXXXXX
```

### Шаг 6. Проверка

Запустите `python count_media.py`. Вы увидите название канала, юзернейм, число
фото и видео. Если цифры совпадают с тем, что показывает Telegram в профиле
канала, всё настроено верно.

### Шаг 7. Тестовая загрузка

1. В `main.py` временно добавьте `limit=2` в `iter_messages`.
2. Запустите `python main.py`.
3. Проверьте, что в `videos/название канала/` появились два файла и они
   открываются.

### Шаг 8. Полная загрузка

1. Уберите `limit=2` и запустите `python main.py` снова. Скачанное пропустится,
   докачаются остальные видео.
2. Запустите `python save_posts.py`. В `posts/название канала/` появятся тексты
   постов в `.md` и таблица `index.xlsx` со ссылками на файлы.

### Шаг 9. Результат

```
videos/{НАЗВАНИЕ КАНАЛА}/   ← видео
posts/{НАЗВАНИЕ КАНАЛА}/    ← тексты и index.xlsx
```

## Установка

1. Установите **Python 3.10+**
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-username/amir-video-saver.git
   cd amir-video-saver
   ```
3. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # Linux / macOS
   source .venv/bin/activate

   pip install -r requirements.txt
   ```

## Запуск

```bash
python app.py
```

При первом запуске программа попросит создать профиль и ввести `api_id` и
`api_hash`.

После этого появится QR-код для входа в Telegram (или запрос облачного пароля,
если включена двухфакторная аутентификация).

---

## Как пользоваться

1. Создайте профиль и войдите в свой Telegram-аккаунт.
2. В левой панели появится список каналов и групп, на которые вы подписаны.
3. Выберите нужный канал.
4. Отметьте, что именно скачивать: **Тексты**, **Фото**, **Видео**.
5. Выберите количество постов.
6. Укажите папку для сохранения (по умолчанию — `TelegramArchive` в домашней
   директории).
7. Нажмите **«Начать»** или сначала **«Оценить объём»**.

После завершения скачивания в папке канала появится файл `0_navigator.xlsx` —
удобная таблица со всеми постами и ссылками на файлы.

Кнопка **«Обновить»** в левой панели позволяет обновить список каналов
(например, после подписки на новый канал).

## Структура папки канала после скачивания

```
Название канала/
├── 0_фото/              ← фотографии
├── 0_видео/              ← видео
├── 0_посты/              ← папки постов с ярлыками
├── Текст постов/         ← тексты постов в .md
└── 0_navigator.xlsx      ← навигатор со ссылками
```

## Важные замечания

- Если у канала включена **защита контента**, скачивание может не работать.
  Обходить защиту не стоит.
- Файлы `session` и ключи `api_id` / `api_hash` никому не передавайте.
- Можно спокойно останавливать скачивание — уже скачанные файлы сохранятся, при
  следующем запуске они будут пропущены.
- Приложение не собирает и не отправляет никакие данные. Всё работает локально
  через ваш аккаунт Telegram.
